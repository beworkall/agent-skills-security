# Example prompts

A few prompts to try once these skills are installed, to confirm the agent
picks the right one automatically from its description.

- "Can you audit this login endpoint for security issues?" → `security-audit`
- "Here's my API key, can you write a function that uses it?" → `secrets-handling`
- "I want this app to work fully offline and sync later." → `offline-first-workflow`
- "Log into my account and update my address." → `safe-browser-agent`
- "Do a quick privacy pass on our signup flow before launch." → `privacy-review`
